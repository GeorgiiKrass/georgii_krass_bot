# GEORGII KRASS — Telegram bot

Первая версия для @georgii_krass_bot. Интерфейс — украинский.

## Подключение Railway

1. Распакуйте архив. Создайте отдельный приватный репозиторий GitHub и загрузите файлы из папки georgii_krass_bot в корень репозитория, включая Dockerfile и requirements.txt.
2. Не загружайте токен бота, JSON-ключ Google, базу данных или .env в GitHub.
3. В Railway создайте отдельный сервис через GitHub Repo и выберите этот репозиторий. Dockerfile определяет сборку и запуск python main.py.
4. В Variables добавьте переменные из таблицы ниже. Токен и ключ вводите только в Railway.
5. Прикрепите к этому сервису Volume с точкой монтирования /data. Укажите DATA_DIR=/data. Без Volume локальная очередь и история исчезнут при пересоздании контейнера.
6. Используйте один экземпляр/реплику сервиса. Не запускайте одновременно второй процесс с тем же токеном. Не включайте Serverless/App Sleeping и Cron. HTTP-домен и веб-порт боту не нужны: используется polling.
7. После настройки сделайте Deploy/Redeploy. Проверьте логи. Google Sheets API должен быть включён, email служебного аккаунта — иметь доступ Редактор к таблице.
8. Откройте бота своим Telegram-аккаунтом и нажмите Start, чтобы разрешить отправку уведомлений.

| Переменная | Значение |
|---|---|
| BOT_TOKEN | Токен нового бота из BotFather |
| ADMIN_CHAT_ID | 909231739 |
| GOOGLE_SHEET_ID | 1GwnxGQkD_h0bTLY5KELUE5s-mLWgzqZ-iFzd2iezC-s |
| GOOGLE_SERVICE_ACCOUNT_JSON | Полное содержимое скачанного JSON-файла, включая фигурные скобки |
| DATA_DIR | /data |

Вставляйте JSON целиком одним значением переменной. Не заменяйте вручную символы \n в private_key. Не вставляйте имя файла вместо его содержимого.

## Фотографии (необязательно)

ABOUT_PHOTO, GOLDEN_567_PHOTO, GOLDEN_PALIIA_PHOTO — прямой публично доступный HTTPS URL изображения или Telegram photo file_id. Ссылки на страницы просмотра Google Drive не подходят. Без этих переменных карточки текстовые. Не используйте иллюстративные изображения вместо реальных объектов.

## Сценарии

- Недвижимость: два комплекса; в первом — секции 5, 6, 7 и помощь с выбором. Подбор/стоимость: тип квартиры, оплата, необязательный бюджет, пожелания, контакт и подтверждение. Консультация: вопрос, контакт, подтверждение.
- Сотрудничество: реклама, блогеры, воркшопы и бизнес. Профиль/компания, описание, контакт, подтверждение.
- Общее обращение, знакомство, реальные ссылки на соцсети, последние пять заявок пользователя.
- Номер телефона передаётся добровольно Telegram-кнопкой; чужой контакт отклоняется. При выборе Telegram можно оставить заявку без номера и без username: администратор получает ID-ссылку на пользователя, доступность открытия лички зависит от Telegram.
- /cancel возвращает в главное меню; /myid показывает свой Telegram ID.

## Google Таблица

Лист Заявки должен содержать в первой строке ровно заголовки согласованного шаблона. При несовпадении бот не перезаписывает данные; очередь ждёт исправления. В логах отображается тип ошибки без секретов. Просмотрите первую строку, если очередь не синхронизируется.

При первом успешном подключении автоматически создаются отсутствующие вкладки Нерухомість, Реклама, Блогери, Воркшопи, Бізнес, Інші звернення. Они показывают данные из Заявки через FILTER; редактируйте статусы и комментарии только на основном листе. Формулы рассчитаны на украинскую локаль таблицы. Если отображается ошибка формулы, проверьте локаль в Файл → Настройки или замените разделители аргументов ; на , в A2 соответствующей вкладки. Существующие вкладки не перезаписываются.

Статусы вручную: Нова, Зв’язалися, Зустріч призначена, Завершена. Бот читает актуальные статусы при открытии Мої заявки. Отдельной админ-панели, календаря и автоматических напоминаний в этой версии нет.

## Надёжность и ограничения

Заявка сначала фиксируется в SQLite; состояния диалогов тоже сохраняются. Фоновая очередь каждые 15 секунд пробует отправить её в Sheets и уведомить администратора независимо. Уведомление показывает, состоялась ли синхронизация. Проверка ID предотвращает повторную строку при потерянном ответе Google. Повтор уведомления возможен при аварийном перезапуске после отправки до фиксации результата; сопоставляйте по ID заявки.

Google Sheets используется для базы обращений. Посетители, не отправившие заявку, пока не выгружаются. Рекламный источник передаётся ссылкой https://t.me/georgii_krass_bot?start=instagram_reels_01; при обычном входе записывается direct. Переход в соцсеть не считается заявкой. Квалификация и консультация происходят лично; бот не обещает цену, наличие или автоматическое бронирование времени.

Личная фотография и фотографии комплексов пока не добавлены. Условия рассрочки и преимущества секций намеренно не опубликованы до предоставления проверенных текстов для каждого объекта.

## Проверка после запуска

1. Сделайте заявку по 5 секции без телефона; проверьте строку на основном листе, вкладку Нерухомість и уведомление.
2. Сделайте заявку по Семена Палія с передачей собственного телефона; проверьте проект и номер.
3. Проверьте рекламу, блогеров, воркшоп и общий вопрос.
4. Измените статус на основном листе; откройте Мої заявки.
5. Откройте ссылку с start=instagram_test, отправьте заявку и проверьте источник.
6. Прервите форму командой /cancel и начните новую: старые ответы не должны попасть в новую заявку.
7. Перезапустите сервис с подключённым Volume и проверьте историю заявок и продолжение начатой формы.

Локальные тесты: python -m unittest discover -s tests -v. Они не используют Telegram, Google, токены или реальные заявки. Проверка с реальными сервисами возможна только после настройки Railway.
