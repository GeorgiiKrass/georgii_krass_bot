# GEORGII KRASS — Telegram bot v3

Готовая визуальная версия для `@georgii_krass_bot`. Интерфейс бота — украинский.

## Что уже встроено

- приветственный экран с изображением и кнопкой `▶️ СТАРТ`;
- раздел `🏙 ЖК GOLDEN CITY` с двумя фотокарточками;
- отдельные страницы и видео для 5–7 секций и GOLDEN CITY на Семена Палія;
- кнопка единого отдела продаж;
- запись на консультацию через `@Manager_Georgii_Krass` с готовым текстом;
- четыре формата сотрудничества с отдельными сообщениями менеджеру;
- соцсети, информация о Georgii Krass и форма общего обращения;
- фиксация пользователей, источников, действий и заявок в Google Таблице;
- локальная очередь SQLite, сохраняющая данные при временной недоступности Google.

Изображения и видео находятся в папке `assets`. Загружать их отдельно или добавлять ссылки в Railway Variables не нужно.

## Обновление репозитория GitHub

Загрузите **всё содержимое этой папки в корень репозитория** `georgii_krass_bot`:

- `assets/`;
- `tests/`;
- `Dockerfile`;
- `main.py`;
- `store.py`;
- `requirements.txt`;
- `README.md`;
- `.gitignore`.

Токен Telegram, JSON-ключ Google, `.env`, базу SQLite и папку `.venv` загружать в GitHub нельзя.

После загрузки Railway должен автоматически начать новый Deploy. Если этого не произошло, откройте проект Railway и нажмите `Redeploy`.

Оставьте следующие переменные:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | Токен бота из BotFather |
| `ADMIN_CHAT_ID` | `909231739` |
| `GOOGLE_SHEET_ID` | `1GwnxGQkD_h0bTLY5KELUE5s-mLWgzqZ-iFzd2iezC-s` |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | Полное содержимое JSON-ключа служебного аккаунта |

Старые переменные `MAIN_PHOTO`, `GOLDEN_567_*`, `GOLDEN_PALIIA_*` и ссылки карт больше не используются — их можно удалить после успешной проверки новой версии.

Volume Railway должен быть подключён к `/data`. Используйте только одну реплику сервиса, поскольку бот работает через Telegram polling.

## Google Таблица

Бот автоматически создаёт три вкладки:

### `Користувачі`

Каждый пользователь, который нажал Telegram Start. Сохраняются первая и последняя активность, Telegram ID, имя, username, язык, первое и последнее джерело перехода, количество запусков и последнее действие.

### `Переходи`

История действий: запуск бота, открытие меню, раздела, жилого комплекса, видео, консультации или формата сотрудничества.

### `Заявки`

Общие обращения, клики по записи на консультацию и выбранные форматы сотрудничества. Новые заявки также отправляются администратору в Telegram.

Если вкладка уже существует и её первая строка отличается от шаблона, бот не перезаписывает её. Исправьте или очистите заголовки и сделайте Redeploy.

| Facebook | `https://t.me/georgii_krass_bot?start=facebook` |
| Наружка | `https://t.me/georgii_krass_bot?start=outdoor` |
| Meta Ads | `https://t.me/georgii_krass_bot?start=meta_ads` |

Telegram передаёт источник только после нажатия пользователем кнопки Start. Само открытие страницы бота без запуска невозможно зафиксировать через Telegram Bot API.

## Проверка после Deploy

1. Откройте бота и нажмите Start.
2. Проверьте главное изображение и кнопку `▶️ СТАРТ`.
3. Откройте оба ЖК, изображения и оба видео.
4. Проверьте кнопку `📍 ВІДДІЛ ПРОДАЖУ` — она должна открыть одну общую точку Google Maps.
5. Нажмите запись на консультацию и один формат сотрудничества.
6. Отправьте тестовое общее обращение.
7. В Google Таблице проверьте вкладки `Користувачі`, `Переходи`, `Заявки`.
8. Откройте ссылку с `?start=instagram` и убедитесь, что источник записался как Instagram.

Локальная проверка кода:

```bash
python -m unittest discover -s tests -v
```
